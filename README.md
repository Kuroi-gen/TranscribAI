# 🎙️ TranscribAI

Windows 11 向けの **リアルタイム音声文字起こし ＆ AI要約 デスクトップアプリケーション** です。  
（Windows標準の音声入力 `Win + H` の認識精度やマウス操作時の自動停止の課題を解消するために開発されました。設計・通信基盤は [PopAI](https://github.com/Kuroi-gen/PopAI) を参考にしています）

---

## ✨ 主な機能

1. **他のマウス・キーボード操作を一切妨げないバックグラウンド録音 (`QThread` + `PyAudioWPatch`)**
   - **「⏺ 録音開始 / ⏹ 録音停止」** および **「⏸ 一時停止 / ▶ 再開」** ボタンを搭載。
   - 録音中に別ウィンドウをクリックしたりキーボード入力しても録音が途切れません。
   - 音声入力ソースをプルダウンから選択可能：
     - `🎤+🔊 マイク＋PC内部音声（会議・汎用）`
     - `🎤 マイクのみ（自分の声）`
     - `🔊 PC内部音声のみ（Web会議・動画音声）`（WASAPI Loopback 対応）
2. **前提プロンプト（プリセット）による文字起こし精度の向上**
   - 専門用語・社内用語・人名などを「前提プロンプト」としてプルダウンから選択・直接編集可能（`presets.json` に保存）。
   - 文字起こしリクエストおよびAI要約リクエストの双方にコンテキストとして自動付与されます。
3. **Azure OpenAI API によるリアルタイム文字起こし ＆ ワンクリックAI要約**
   - 発話の区切り（無音検知 / 一定秒数）ごとに自動で音声チャンクを送信し、上段ペインへリアルタイム追記。
   - **「📝 AIで要約する」** ボタンで、文字起こしテキスト全体の要点・決定事項・TODOを下段ペインへ構造化表示。
4. **API設定・接続テスト ＆ 使えるモデル一覧の自動更新機能**
   - APIキーはアプリケーション本体とは分離された外部ファイル（`.env`、Git管理外）に保存。
   - 初回起動時（または右上の「⚙️ API設定」ボタン）から開くダイアログで、**「🔄 使えるモデル一覧を更新」** を実行すると、利用可能なモデル（`gpt-4o`, `gpt-4.1`, `whisper`, `gpt-4o-transcribe`, `gpt-4o-audio-preview` 等）を自動スキャンしてプルダウンに登録し、**使えなくなったモデルは自動的に非表示**にします。

## 🚀 セットアップと起動方法

### 1. 依存パッケージのインストール

```powershell
pip install -r requirements.txt
```

### 2. アプリケーションの起動

- **ダブルクリックで起動（コンソール非表示）**:
  - `start_transcribai.bat` または `main.pyw` をダブルクリック
- **コマンドラインから起動（ログ表示あり）**:
  ```powershell
  python main.py
  ```

### 3. APIキーの設定（初回起動時）

1. 初回起動時に自動で **「🔑 Azure OpenAI API 設定・モデル管理」** ダイアログが表示されます（APIキーなしで試す場合は「🧪 ダミーモードで開始」を選択できます）。
2. **「エンドポイント URL」** と **「API キー」** を入力し、**「🔄 使えるモデル一覧を更新」** を押すと、現在使えるモデルが自動判別されてプルダウンにセットされます。
3. **「💾 設定を保存して適用」** を押すと `.env` ファイルに保存され、すぐにご利用いただけます。

詳しい設定手順やトラブルシューティングは [setup_guide.md](setup_guide.md) を参照してください。
